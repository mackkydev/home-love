# บ้านใจ — Home Organizer

ต้นแบบเว็บแอป Next.js สำหรับจัดการบันทึกและของใช้ในครอบครัว ออกแบบเป็น mobile-first PWA

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

จากนั้นเปิด `http://localhost:3000` ถ้าพอร์ตนี้ถูกใช้งานอยู่ Next.js จะเลือกพอร์ตถัดไปให้อัตโนมัติ

## ฟังก์ชันในต้นแบบ

- สรุปค่าใช้จ่ายและจำนวนรายการของบ้าน
- หมวดหมู่เริ่มต้นและเพิ่มหมวดหมู่เอง
- บันทึกรายการซื้อและข้อมูลทั่วไป
- บันทึกแพ็กเกจบริการพร้อมจำนวนครั้งคงเหลือและปุ่มใช้ 1 ครั้ง
- เก็บประวัติการใช้บริการต่อรายการ
- ค้นหา กรองหมวดหมู่ ลบรายการ และส่งออกไฟล์สำรอง JSON
- บันทึกข้อมูลใน `localStorage` ของเบราว์เซอร์ พร้อม web manifest และ service worker

## ข้อจำกัดของต้นแบบ

ข้อมูลยังอยู่เฉพาะเบราว์เซอร์และอุปกรณ์นี้ จึงยังไม่ซิงก์ระหว่างสมาชิกครอบครัว และยังไม่มีระบบล็อกอิน/เชิญสมาชิก/ฐานข้อมูลกลาง การทำงานหลายอุปกรณ์ต้องเชื่อมบริการฐานข้อมูลและยืนยันตัวตนก่อนใช้งานจริง

ไม่ควรเก็บรหัสผ่านสำคัญในต้นแบบนี้
