# การโหลดแอปและตัวเลือกที่เพิ่มเอง

หน้าโหลดแสดงจาก `AppStartupGate` เพียงจุดเดียว โดยรอครบอย่างน้อย 3 วินาที รอตรวจสิทธิ์บัญชี และรอข้อมูลเริ่มต้น การตรวจเวอร์ชันมีเวลารอสูงสุด 5 วินาที เพื่อให้ยังเข้าแอปได้เมื่อเครือข่ายมีปัญหา

เมื่อพบเวอร์ชันใหม่ระหว่างเริ่มต้น จะแสดงปุ่ม **อัปเดตตอนนี้** และ **เข้าแอปก่อน** บนหน้าโหลด หากพบภายหลังเข้าใช้งาน จะแจ้งให้ผู้ใช้เปิดหน้าอัปเดตเองเพื่อไม่ขัดจังหวะฟอร์มที่กำลังกรอก เมื่อกดอัปเดต ระบบสั่งเปิด worker ใหม่และ reload เพียงครั้งเดียวต่อการกด ใช้ session marker นับเวลาหน้าโหลดต่อจากรอบเดิม การติดตั้งแอปครั้งแรกไม่แสดงเป็นการอัปเดตซ้ำ

Dropdown ร้าน ชื่อคน หน่วย และสินค้า ดึงตัวเลือกจากรายการที่บันทึกในบ้าน ตัวเลือกที่เพิ่งเพิ่มแต่ยังไม่ได้บันทึกรายการจะจำในอุปกรณ์ โดยแยกตามบัญชีและบ้าน เมื่อบันทึกรายการสำเร็จ ตัวเลือกจะมาจากข้อมูลบ้านและใช้ได้บนอุปกรณ์อื่นด้วย

ชื่อเทียบกันด้วย Unicode normalization ตัวพิมพ์ และช่องว่าง จึงไม่เสนอเพิ่มชื่อซ้ำจากความต่างเหล่านี้ การค้นหาและการกด Enter ใช้ชื่อเดิมเมื่อมีอยู่แล้ว โดยไม่ submit ฟอร์มหลัก หน่วยหรือขนาดยาที่ต่างกันยังแยกเป็นคนละตัวเลือก

## รอบส่งแจ้งเตือน

งานเดิมชื่อ `home-love-push-minute` สามารถใช้รอบ 30 วินาทีโดยคงคำสั่งและ Vault secret เดิมได้:

```sql
select cron.alter_job(
  job_id := (select jobid from cron.job where jobname = 'home-love-push-minute'),
  schedule := '30 seconds'
);
```

ชื่อ job เดิมไม่ใช่ตัวกำหนดความถี่ ให้ดูคอลัมน์ `schedule` และประวัติการทำงาน สำหรับการตั้งใหม่ใช้ `supabase/setup_push_scheduler.sql` ตามเดิม
